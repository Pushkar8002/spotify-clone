# 🎵 Spotify Clone

A simple **Spotify Clone** made using **HTML, CSS, and JavaScript**.
This project is created for practicing basic frontend web development and JavaScript functionality.

## 🚀 Features

* 🎵 Spotify-inspired user interface
* ▶️ Play and pause songs
* ⏭️ Next and previous song controls
* 🎶 Song list
* 🔊 Basic music player controls
* 📱 Simple and responsive design

## 🛠️ Technologies Used

* **HTML** – Structure of the website
* **CSS** – Styling and layout
* **JavaScript** – Music player functionality

## 📂 Project Structure

```text
Spotify-Clone/
│
├── index.html
├── style.css
├── script.js
└── assets/
    ├── images/
    └── songs/
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enjoy the Spotify Clone.

This project was created as a **frontend practice project** to improve my skills in HTML, CSS, and JavaScript.
